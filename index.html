About the repository

From equations to flow fields

This project brings together fluid mechanics models and experiments, including shallow-water dynamics, Kelvin–Helmholtz instability, external flows and Navier–Stokes-related numerical investigations. Some studies solve differential equations numerically; others visualize known analytical solutions. The animations illustrate the outputs, while the repository preserves the underlying source code.
